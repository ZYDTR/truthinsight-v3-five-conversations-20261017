# 候选解释与有效检验

把科学问题转换成可以被现有数据区分的主张，选择适合其独立单位和变量定义的分析。简单基线、无结构或无效应解释，应与更复杂的候选使用可比较的数据和评价条件。

针对可能改变结论的混杂、平滑变化、局部变化、有限样本、分组差异、派生关系等提出合理竞争解释。无需枚举所有模型，但应说明为何选择这些比较、还有哪些解释无法检验。拟合优度或候选排序只能支持其实际比较范围。

稳健性检验应改变关键假设，而不只是把同一计算重复多次。例如按真实组留出、改变合理分析窗口、采用另一种估计定义或模型复杂度。记录结论是否保持、效应量变化及失败范围；尽量把选择和验证分开，说明任何重复使用数据造成的乐观偏差。

对涉及零假设、随机化或注入对照的检验，检查它究竟保留和破坏了什么。若它保留了待测结构本身，就不能据此排除该结构。检验未发现效果时，应说明它对哪些大小、形状和尺度的信号有识别能力；能力未知时保留未解决结论。

多个检验、筛选后报告与参数搜索会改变不确定性的解释，使用与主张相符的控制或明确探索性质。避免把单次最优参数、无法分离的交互或任意显著阈值写成稳定机制。

优先形成具有信息量的结论：观测关系是什么、替代解释哪里受限、结论在哪些条件下失效。定义中已有的恒等式和输入文件内给定的关系可用作质量检查，但作为科学发现时须说明新增了什么可验证信息。

每个用于支持或排除解释的检查，都要能连接：待区分的主张、改变的假设、实际结果和允许更新的结论范围。保留原结构的置换、同一观测的插值或由原数据推导的再采样，可能只检查数值表现，不能自动充当独立验证。未发现差异与证明等价不同；识别能力未知时保留未决解释。

模型比较必须共享可比较的观测对象、尺度与评价定义。似然、信息准则或误差指标的归一化、参数计数和数据支持范围不一致时，先建立可比口径或明确该排序无效，不能保留以它为依据的优劣标题。拟合改善只支持已比较候选，不自动证明唯一机制。

结论状态必须由本轮真实结果决定。对照失败、稳健性不成立、分组估计冲突或误差传播改变方向时，受影响主张应撤回、收窄或改为未决；固定的“全部稳定/已排除”文字不能覆盖相反的表格结果。保留异常、失败范围及有效阴性结果，不为满足报告数量制造发现。
